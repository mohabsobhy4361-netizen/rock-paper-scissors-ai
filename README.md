# 🎮 Rock Paper Scissors with GUI & AI

## 📌 About the Project

أنا عملت المشروع ده باستخدام **Python**، وهو عبارة عن لعبة Rock Paper Scissors التقليدية، لكن بدل ما ألعب من خلال الـ Terminal، عملت **GUI (Graphical User Interface)** عشان أخلي اللعب أسهل وأوضح.

اللاعب بيختار Rock أو Paper أو Scissors، والـ AI بيختار هو كمان، وبعد كده البرنامج بيقارن الاختيارين ويحدد نتيجة الجولة.

## 🎯 Game Rules

- 🪨 **Rock** beats Scissors.
- 📄 **Paper** beats Rock.
- ✂️ **Scissors** beats Paper.

لو اللاعب والـ AI اختاروا نفس الحاجة، الجولة بتكون تعادل.

## ✨ Features

- واجهة رسومية **GUI** للتفاعل مع اللعبة.
- اللعب ضد **AI**.
- تحديد نتيجة كل جولة تلقائيًا.
- تطبيق عملي لمفاهيم Python والـ Game Logic.

## 🛠️ Technologies Used

- Python
- GUI
- Git & GitHub

## 🚀 How to Run the Project

### 1. Clone the Repository

افتح الـ Terminal واكتب:

```bash
git clone https://github.com/mohabsobhy4361-netizen/rock-paper-scissors-ai.git
```

### 2. Open the Project Folder

```bash
cd rock-paper-scissors-ai
```

### 3. Run the Game

اتأكد إن Python 3 متثبت عندك، وبعدها شغّل ملف اللعبة:

```bash
python3 "# ruck and paper and scissors with GUI ,AI.py"
```

لو ظهرت رسالة إن فيه Library ناقصة، ثبّت المكتبة المطلوبة قبل تشغيل اللعبة.
